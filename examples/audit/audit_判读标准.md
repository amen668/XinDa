# 自动放行单元人工抽检·判读标准（单人核校协议）

**对应论文位置**：§4.5 残余事实错误率抽检（大修必答项）
**抽样清单**：`audit_sample.csv`（同目录）
**抽样方法**：从 10 个 job（5,14,20,35,43,54,60,61,107,115）门控自动放行的全部 1854 个单元中，
按 job 分层、比例分配、固定种子（seed=42）随机抽取 320 个；行序已整体打乱。
复现命令：`python -m xinda.cli.export_audit_sample --n 320 --seed 42`

## 核校配置（如实声明，随论文公开）

- **人工裁决**：作者一人，借助机器翻译（谷歌翻译等）辅助理解英文源文——判读以语言无关
  锚点为先（见下），机器翻译仅用于比较方向与语义类条目的参考，不作最终依据；
- **独立筛查器**：异厂商大模型（与翻译所用 Qwen 不同厂商）对全部 320 行独立给出
  "源文事实点中文清单 + 判定建议 + 理由"，填入"筛查器"各列。筛查器只提异议，**裁决权在人**；
- **两阶段人工核校（验证抽样）**：机器筛查（异厂商筛查器 + 确定性锚点机检）覆盖全部 320 行；
  人工裁决按 CSV"两阶段复核"列分两层——①**异常层**（筛查器报错或锚点机检有提示，共 71 行）
  **全数**逐行裁决；②**双绿层**（两项机检均无异常，共 249 行）按固定种子（seed=42）随机抽取
  50 行裁决，用于估计机检双绿情形下的漏检率。双绿层未抽中的行不做人工裁决；
  个别在分层确定前已判的双绿未抽中行（如行 1）保留判定作补充记录，**不进入估计量**；
- **分歧处理**：人工判定与筛查器建议不一致的行，逐条复核并在备注记录理由；
- **自评一致性**：全部判完后隔期（建议 ≥1 周）对**已人工裁决行**中的随机 40 行子样本
  打乱顺序复判一遍，报告自评一致率，作为单人核校稳定性证据；
- **公开**：抽样清单、本标准、含全部判定与备注的核校记录随评测数据一并公开。

## 判读流程（每行按序执行，多数行到第 2 步即可判定）

1. **占位符核对（不需要英语）**：源、译两侧的 `{{PT_…}}` 令牌应逐字一致——个数、编号、
   相对顺序都不得变化。不一致 → 事实错误（类型按令牌含义填：引用/符号/其他）。
2. **锚点核对（不需要英语）**：逐一圈出源文中的数字（含单位、正负号、百分号、数量级）、
   变量与符号、专有方法/模型/数据集名，在译文中找到对应项逐字核对。
   任何改变、丢失、凭空新增 → 事实错误。
3. **比较方向核对（需要语义判断）**：找出源文中的比较/趋势论断（A 高于/低于/优于 B，
   增大/减小，至少/至多）。先看筛查器给出的中文事实清单，再用第二参考译文（谷歌）交叉：
   两版中文方向一致且与我们译文一致 → 保真；不一致 → 对照下方方向词表细读源文原句裁决。
4. **整句漏译/增译**：源文含实质论断而译文整体缺失，或译文出现源文没有的论断 → 事实错误（其他/丢失）。
5. 仍无法裁决（源文本身歧义、单元过短缺语境）→ **不确定**，备注写明原因。

## 常见方向词速查（第 3 步用）

| 英文 | 方向 | 英文 | 方向 |
|---|---|---|---|
| higher / greater / larger / exceeds | 高于/大于 | lower / smaller / less than | 低于/小于 |
| outperforms / superior to / better than | 优于 | inferior to / worse than | 劣于 |
| increases / grows / improves | 增大/改善 | decreases / declines / degrades | 减小/退化 |
| at least / no less than | 不少于（下界） | at most / no more than / up to | 不超过（上界） |
| comparable / on par with / similar to | 相当 | negligible / insignificant | 可忽略/不显著 |

## 判定取值（只看“事实保真”，不评流畅度/文风）

| 判定 | 含义 |
|---|---|
| 保真 | 全部可核验事实无失真：数值、占位符、比较方向、方法名、符号 |
| 事实错误 | 上述任一类发生改变、反转、丢失或凭空增加 |
| 不确定 | 无法裁决（不计入错误率分母，备注必填原因） |

**错误类型**（判“事实错误”时必填，可多选、逗号分隔）：数值 / 引用 / 比较 / 方法名 / 符号 / 其他。
术语选词不当、译文生硬**不属于**事实错误（判“保真”，可备注），除非选词改变了事实含义。

## 结果统计（两阶段验证抽样估计）

设异常层 N₁=71（全数核校，查实错误 e₁ 行，不确定 u₁ 行）、双绿层 N₂=249
（抽 n₂=50 核校，查实错误 e₂ 行，不确定 u₂ 行）。

残余事实错误率（分层估计）：

```
p̂ = [ e₁ + (e₂/(n₂−u₂))·N₂ ] ÷ (N₁−u₁ + N₂)
```

即异常层用普查值、双绿层用抽样错误率外推到全层；"不确定"行从所在层分母中剔除。
95% 置信区间按分层抽样方差合成（异常层为普查、方差为 0，仅双绿层贡献抽样方差，
用 Wilson 法求双绿层错误率区间后按权重 N₂/(N₁+N₂) 缩放合成）。
同时报告：分错误类型分布、人工-筛查器分歧率（在人工裁决行上计算）、自评一致率。
结果填入论文 §4.5。

## 实测结果（2026-06-13 核校完成）

- 异常层 N₁=71：事实错误 e₁=50、不确定 u₁=9、保真 12（全数核校）。
- 双绿层 N₂=249：抽 n₂=50，事实错误 e₂=0、不确定 u₂=0（全为保真）。
- **总锚点偏差率（分层）= 50/311 = 16.1%。**

**对 50 个偏差行逐条归因**（区分事实保真 vs 结构保留两类）：

| 子类 | 行数 | 说明 |
|---|---|---|
| 仅 `{{NL}}` 换行符令牌增减 | 42 | 影响分段/换行，词面事实未变；属结构保留范畴，源于回填阶段令牌还原，可确定性补全修复 |
| 公式符号未以占位符令牌还原 | 1（行318） | a/b/c 含义保留、LaTeX 标记丢失；同属结构保留 |
| **真·残余事实错误** | **7**（行 7,48,57,117,131,133,160） | 见下 |

7 个真事实错误：天体名误译 1（行48 HR 8799→另一星名）、增译时间限定 1（行117）、
术语/方法名错译 5（其中 "rollout"→"软件包推出" 重复 3 次：行 7/131/133，单一术语未接地根因；
行57 Packing→压缩；行160 departures→偏离）。

- **残余事实错误率（分层）= 7/311 = 2.3%**；异常层为普查（7 例确证），双绿层 0/50 →
  Wilson 上界 7.1%，合成 95% 区间 ≈ [2.3%, 8.0%]。
- 占位符/换行完整性偏差 = 43/311 = 13.8%（几乎全为 `{{NL}}`），单列、不计入事实错误率。
- 9 个不确定（术语取舍＋语境歧义），剔除分母。
- **人工-筛查器分歧率 = 51/122 = 41.8%**；分歧几乎全在 `{{NL}}` 维度（筛查器对换行不敏感、
  确定性锚点机检在该维度更可靠），语义类事实错误上人机高度一致。
- 隔期自评一致率：拟于 ≥1 周后对已裁决行随机 40 行复判，作为单人核校稳定性补充证据（待补）。
