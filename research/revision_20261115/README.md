# 全文双语出版实验复现资料

本目录提供2026年11月15日整理的公开复现资料：50篇中文结构验证的许可源文、保存的译文及提示词/响应，旧输入方式和五模型实验的逐篇指标，以及匿名历史批量运行统计。数据来自既有实验归档；本次整理没有重新调用翻译模型。论文稿件、审稿意见和编辑文件不属于本包。

## 离线复算

在仓库根目录，使用 Python 3.10 或更新版本。提前安装依赖后，复算不访问网络、数据库或模型 API，也不读取任何凭据文件。

```sh
python -m pip install -r research/revision_20261115/requirements-offline.txt
python research/revision_20261115/scripts/recompute_all.py
```

第一条安装命令可能联网；第二条仅操作本地归档和仓库中的 `examples/audit`。它先核验 `checksums.json`，再解压到本目录被 Git 忽略的 `.recompute/chinese50/`，运行三项中文分析及旧实验、历史运行记录复算，比较五个中文汇总文件与原归档值。结果写入 `.recompute/verification_result.json`。重复执行只覆盖这个工作副本的派生结果，不修改公开归档或历史响应。

也可单独核对不依赖 lxml 的旧记录：

```sh
python research/revision_20261115/scripts/recompute_legacy.py
python research/revision_20261115/scripts/recompute_history.py
```

## 解压后的中文数据

`source_xml/`保存50篇原始JATS XML；`experiment/sources/`保存翻译单元与XPath；`experiment/runs/<PMCID>/<输入方式>/`保存实际批次提示词、响应、单元对及译后XML；`experiment/challenge_responses/`保存100次命题核查的原始提示词和响应。`experiment/protocol.json`记录模型别名、温度和分批规则。

三个离线脚本依次是 `experiment/analyze.py`、`experiment/analyze_tables_zh.py`、`experiment/audit_article_structure.py`。为固定提取—回填测试，包内仅保留历史版本的XML处理、格式配置和占位符纯函数，未携带数据库配置、供应商连接或服务入口；这些副本不会替换当前仓库的 `xinda/`。

命题判定使用的规则、模型输出及构造标签可核对，但尚未经独立领域专家标注。英文改写来自本研究，并不表示原作者认可。详见[许可与署名](LICENSES.md)、[指标解释边界](methods/BOUNDARIES.md)及[公开副本调整说明](CHANGELOG.md)。

## 实验结果的适用范围

- 占位符条件的公式匹配为143/143，上下标仅33/2388；扩展保护后2388/2388来自不调用模型的提取—回填测试，不能当作改进后翻译质量结果。
- 40组英译中样例来自34个源段；34/40是异常标记比例，部分焦点改写未确证，不是事实差错检出率。QA两侧分别出题，分差也受题目变化影响。
- 10篇记录中复检后1854/2230未标记，即83.1%；未标记不等于正确，也不意味着人工工时下降83.1%。旧抽样标签有争议，不计算残余事实错误率。
- 每篇约0.033—0.044元仅为按项目参考费率折算的翻译调用费用，不是实际账单或总成本；不含核查、转换与人工审校。
- 历史批量核查比较已保存双语输出的两栏，未独立重读历史源文件；高逐元素匹配率不能替代逐篇、语义及专业内容检查。

`scripts/build_public_package.py`是本包的筛选与重打包工具，面向持有原归档的维护者；普通读者只需使用上面的离线复算命令。原始私有归档不随仓库发布。
